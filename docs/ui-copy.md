# 桌面文案约定

操作页面以“做什么、当前是什么状态、接下来需要做什么”为主。字段名直接表达用途，避免在页标题、卡片标题、字段下方反复解释同一件事。

## 页面层级

- 侧栏上方放控制台、钓鱼设置、自动制作、识别阈值；下方固定设置和使用说明。
- 控制台先显示运行状态和启动按钮，再显示目标窗口；画面配置按需展开，前台模式自动展开。日志与识别诊断保留在下方。
- 钓鱼设置分为“收鱼策略 / 自动续钓 / 背包清理”；设置分为“常规 / 更新与关于 / 诊断 / 调试”。使用共享 `SectionedPage`，不要复制导航实现。
- 页内标签始终可见，内容独立滚动。滚轮不得意外切换标签或修改参数；鼠标点击和键盘导航保持可用。
- 卡片按内容高度排列，不把单个参数区拉伸填满窗口。危险提示必须和相应开关或测试按钮在同一分类中，不能藏进折叠说明。
- 核心操作在 920×680 的最小窗口仍应可见；页面变长时允许垂直滚动，不出现横向裁切。

## 文案层级

## 字体与间距

- 公共规则放 `desktop/design.py`：正文/输入项 14、辅助说明 13、次要标记 12、卡片标题 16、页标题 24。以上为 Qt 逻辑像素，随系统 DPI 缩放，不是固定屏幕物理像素。
- 标题适度加粗，正文不使用粗体。字体依次为 Segoe UI、Microsoft YaHei UI、Microsoft YaHei，避免中文回退不明确。数字输入继续使用 C locale，显示与解析保持一致。
- 页面卡片复用 `configure_card_layout()`，默认内边距 16、内容间距 12。不要为了放大文字扩大整个窗口或恢复整页长说明；内容超出时垂直滚动。
- 通过 `cardTitle`、`helper`、`safetyWarning` 等语义角色指定字号，不在页面散落 `font-size` 或临时 `QFont`。悬浮栏使用同模块的紧凑字体规则。
- 改字号后检查双主题、最小窗口、高 DPI、下拉框、等宽状态栏和危险确认文本。使用 `tests/test_desktop_typography.py`；不能只检查控件外框尺寸，也不能截短危险告知来通过测试。

## 文案层级

- 参数解释通过 `desktop/forms.py` 的悬停提示和可访问说明提供，不再为每个字段增加一行小字。
- 计算原理、完整操作流程集中在“使用说明”。模式一仍保留独立的“钓鱼计时”和当前记录，公式与示例放在帮助页。
- 补充步骤使用 `desktop/widgets.py` 的 `DetailsPanel`，默认收起，可用鼠标或键盘展开。它不承担危险告知。
- 运行状态显示当前结果；没有估时或额外提示时不显示占位长句。异常原因保留全文，并写入日志。
- 背包清理的永久分解/出售、可能误用大胆整理、真实测试风险保持直接可见；确认勾选和默认关闭不变。制作消耗材料在开始前确认，诊断分享前保留隐私提醒。
- 旧像素参数只在用户选择兼容模式时显示。不要把实现细节、开发计划或“此处以后会增加”等文字放在操作页；尚未开放的功能只标明状态。

## 技术术语

运行方式、捕获方式、输入方式和图标识别是独立概念，不能笼统称为“OK 后台”或“后台引擎”。参照 ok-nte 将捕获与交互分层的方式，但只命名本项目真实具备的能力，不引入其其他捕获方案或自动回退策略。

| 设置 | 显示名称 | 对应职责 |
| --- | --- | --- |
| 运行方式 | 后台运行（推荐） / 前台运行 | 选定窗口操作或前台系统键鼠操作 |
| 捕获方式 | Windows Graphics Capture（推荐） / PrintWindow（兼容） | 获取目标窗口画面；WGC 是 Windows Graphics Capture 的简称 |
| 输入方式 | 窗口消息（PostMessage） | 后台模式的固定输入方式，只读展示，不伪装成可选项 |
| 识别方式 | 图像模板匹配（推荐） / 像素识别（旧版兼容） | 钓鱼图标识别，与捕获方式独立 |

常用名称由 `desktop/terminology.py` 统一维护；关于和帮助中保留 ok-script / FeatureSet 的准确归属。异常日志使用实际失败组件名称，保留窗口、消息编号、底层错误和处理建议。内部配置值 `window`、`screen`、`ok`、`printwindow`、`pixel` 不随文案更名；更名不能改变用户选择、默认值或失败处理。

本次仅调整文案和展示层级，不改变 OK 优先原则、任务逻辑、参数默认值、更新服务或配置保存规则。后续修改同样检查日间、夜间主题，并运行 `tests/test_ui_copy.py` 与完整回归。
