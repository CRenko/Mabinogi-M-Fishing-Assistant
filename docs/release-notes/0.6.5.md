1. 自动制作增加“材料加工 / 食物制作”子菜单。食物制作先留好入口，下个版本再加入。

3. 调整日间、夜间配色，修正浅色主题下不清楚的文字、输入框和按钮。勾选框加上明确的对钩。
4. 优化背包清理入口：先判断当前页面，再用 OK 文字锚点定位，不再固定按 I。危险开关增加 OK 图案复核，多次确认“大胆整理”关闭才继续；日志补充识别分数和超时步骤。
5. 按页面、交互、识别、执行拆分代码，方便后续维护和增加功能。

背包清理仍为实验性功能、默认关闭。截图回归通过不等于所有实机环境都可用，请先在可控情况下测试。
