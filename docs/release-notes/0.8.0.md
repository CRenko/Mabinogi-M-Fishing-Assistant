# v0.8.0

1. 项目代码分类整理，补齐了「架构导航」和「贡献指南」，后续维护更方便。
2. 新增实验性功能「自动制作」子菜单（菜单已标注“测试”字样）：
   - 启动失败会明确提示原因，并保留上次计数；
   - 防止重复弹窗；
   - 识别日志会指出具体格数不清楚、是否存在边缘截断；
   - 优化制作悬浮栏：不再受钓鱼前台设置影响，显示当前阶段，异常时突出提醒；
   - 减少状态没变化时的重复刷新；
   - 修复超宽屏材料卡片落在搜索范围外的问题：改为按识别锚点定位，不再按固定坐标点击。
3. 预留新功能：补充手机远程监控的预留（尚未启用）。
4. 优化 UI：更新分组功能；修复不同分辨率下文字字号偏小、标题与正文比例不协调、缩放后文字拥挤的问题。
5. 优化说明文案：重复解释改为悬停提示，补充步骤默认收起；计算公式和完整教程集中到“使用说明”。保留背包风险、安全确认和完整报错。明确区分“停止”和“暂停”；修复后台选项看起来被禁用的配色。

自动制作与背包清理仍为实验性功能，截图回归通过不等于所有实机环境都可用，请先在可控情况下测试。
