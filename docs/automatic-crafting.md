# 自动制作

此功能通过 ok-script 的 FeatureSet 进行图像模板匹配，使用 Windows Graphics Capture（WGC）获取窗口画面、PostMessage 发送窗口输入。制作不受钓鱼窗口捕获选项影响，不调用旧版像素识别，也不会在识别失败时自动切换方案。

窗口列表会标明“已最小化”；请恢复游戏窗口后点击“刷新窗口”再开始。最小化不等于游戏已关闭，但此时仍不能截图或操作。游戏可以被其他窗口遮挡。同名多开时请手动选择，刷新不会替换仍有效的手动目标。

## 开始使用

1. 在游戏中打开木材、金属、布料或皮革的加工主界面，显示“全部”配方列表，并关闭材料详情弹窗。
2. 在助手侧边栏打开“自动制作 → 材料加工”，选择加工分类和具体材料。“食物制作”是预留子菜单，本版本尚未开放。
3. 选择“指定加工次数”或“用完材料为止”，确认目标游戏窗口后点击“开始自动制作”。无需 F7 定位。

初次使用建议设为 **1 次**，观察添加、完成和领取是否正常，再增加次数。游戏可以被其他窗口遮挡，但不要最小化、切换加工界面或手动改动队列。制作、钓鱼和背包测试不能同时运行。

未选择窗口时不能开始；确认弹窗打开期间不会重复弹出。若窗口已关闭或任务被拒绝，页面会显示“制作未启动”，保留上次计数，具体原因也可在控制台日志中查看。

无需把游戏改为固定分辨率，也不用填写截图尺寸。制作按 OK 取得的实际游戏客户区截图，排除标题栏和边框，再用多尺度文字/队列特征定位；后台点击使用同一客户区坐标。1080p、2K、4K 和自定义窗口尺寸走相同流程，不按分辨率名单选择点击位置，Windows DPI 也不会重复乘到点击坐标上。

超宽屏会保留文字识别所需的工作图高度，材料搜索范围同时参考已识别的加工标题位置和字号，不再把靠左的材料卡片排除在固定宽度百分比之外。最终是否点击仍取决于 OK 匹配结果，不按预设卡片坐标点击。

控制台会记录“截图 / 客户区 / 窗口 / DPI”。窗口尺寸包含边框，比游戏画面大是正常的；只有客户区截图未同步或识别后客户区/DPI 改变时才阻止操作。制作中若调整了窗口大小或跨不同缩放的显示器移动，请停止后重新开始，让脚本重新核对队列。

## 材料与用时

| 分类 | 材料 | 单次加工 | 例：4 格依次完成 |
| --- | --- | --- | --- |
| 木材 | 木材 | 1分30秒 | 6分钟 |
| 木材 | 木材+ | 12分钟 | 48分钟 |
| 金属 | 铁锭（矿石） | 1分钟 | 4分钟 |
| 金属 | 铁锭（铁矿石） | 1分钟 | 4分钟 |
| 金属 | 钢锭 | 10分钟 | 40分钟 |
| 布料 | 布料 | 1分30秒 | 6分钟 |
| 布料 | 丝绸 | 3分钟 | 12分钟 |
| 布料 | 布料+ | 12分钟 | 48分钟 |
| 皮革 | 皮革 | 1分钟 | 4分钟 |
| 皮革 | 皮革+ | 10分钟 | 40分钟 |

“一次”是向队列添加一个加工项目，不是产出一件物品。队列容量按游戏画面从 1 格开始自动识别，也可以在页面手动填写；多于 4 格时按画面中的多行布局处理。指定 6 次会按实际容量分批加入，例如 4 格时先处理四格，再处理两格。时间按队列顺序累加，仅供预估；不会因为时间到了就直接领取。

## 添加与领取规则

- 先核对左上角的加工分类，再找到所选材料；详情名称匹配后才按一次 Space。不会自动改选其他材料。
- 两种铁锭详情都只显示“铁锭”，会再核对“所需材料”中的矿石/铁矿石，不能凭所选选项猜测；原料不清楚或配方不符就停止。
- 打开材料后，若连续确认仍在主界面、所选材料可见且队列未变，3 秒后最多补点一次。这个补点只负责打开详情，不会重发加工、领取或确认空格。
- 添加后必须确认队列数量增加，才计入本次次数并继续添加。未得到确认会停止，不会重复盲按。
- 空槽通过 OK 遮罩模板匹配，排除炉子等透过圆环的背景干扰；仍核对槽内区域。只看见圆环、无法判断是否有材料时会等待，不会当作空槽继续添加。
- 通常补满当前识别到的队列容量，等待所有已占用格都识别为 **100%** 后点击“全部领取”。完成判断不依赖材料图案。
- 指定次数不足队列容量，或出现“材料不足”提示时，只处理剩余的部分队列；等已加入的项目全部完成、领取后停止。
- 新手或不同设备可能只有 1 格，后续扩容到多格时无需改代码；若选择“自动识别”，脚本会锁定首轮连续确认的实际格数。手动容量与画面不符或队列被截断时会等待，不会盲目添加。
- 领取后识别“加工完成”弹窗，再按 Space 确认；回到空队列后继续下一轮或结束。
- 开始前已有的队列会等待并领取，但不计入本次添加和领取次数。其剩余时间无法从所选配方推算。

## 停止与异常处理

后台模式最小化助手后，可以从悬浮栏点击“暂停 / 继续”。暂停期间游戏队列仍然加工；继续后重新识别画面，保留本次次数和已发送动作的确认状态，不重复添加。助手的识别超时会顺延，游戏预计完成时间不会顺延。

悬浮栏下方的小按钮带暂停/播放图标：黄色“暂停”、绿色“继续”，灰色表示当前不可用。它们与上方只读状态分开显示。

制作始终使用后台模式，不受钓鱼设置中的“前台 / 后台”选择影响。最小化助手后，悬浮栏会显示“窗口 · 已指定”和当前制作阶段；无需为制作按 F7 校准。异常以警示色显示，鼠标悬停可查看原因。若最小化期间制作结束或异常，悬浮栏保留到恢复主窗口，便于发现任务停止；设置中的悬浮栏开关仍然有效。

点击“停止制作”、按 F8 或 Esc 可停止助手操作，不会取消游戏内已开始的加工。重新制作请使用“自动制作”页面的开始按钮；停止后 F8 仍是原有的钓鱼启动快捷键。

识别不清、分类或配方不符、界面切换超时、窗口发生异常时会暂停操作或停止，并记录原因。不会购买材料、升级设备或通过切换其他配方消耗材料。制作期间暂不执行钓鱼用的 F9 诊断，以免干扰后台悬停位置。

客户区操作使用 ok-script 的 PostMessage 组件发送窗口键鼠消息，不移动系统光标。点击时先让悬停稳定，再短暂按住；按下前重新检查任务和窗口几何信息。暂停/停止后不再按下新按键，已经按下的按键仍会释放。消息投递失败会直接报错，不当作点击成功；超时提示会指出打开详情、添加还是领取确认失败。

队列识别不清时，日志会标出待确认的槽位，例如“第 1、3 格”，或提示检查队列边缘是否被截断。请先检查画面；不会把这些未知槽位当作空槽，也不会为继续制作而跳过画面确认。

## 当前验证范围

已使用提供的繁体中文截图验证分类、材料名称、百分比、空槽、领取弹窗和材料不足提示，并进行缩放及模拟布局测试；流程测试使用模拟输入，不会向游戏发送按键。

客户区回归覆盖非标准尺寸、2560×1600、超宽屏、4K，以及 100% / 125% / 150% / 200% DPI 的坐标契约；同时调用安装版 OK 的裁边方法验证带标题栏截图，检查缩放或停止后不再发送旧操作。它们不等同于对应设备的实机验证。

五格空队列与炉子背景重叠的实图已加入回归，覆盖缩放、画面变暗以及材料文字不清时不误判空槽的场景。确认弹窗和悬浮按钮分别检查日间、夜间主题。

尚未完成真实游戏的后台操作验证。不同游戏语言、UI 缩放和实际输入响应仍需实机确认。功能纳入 0.6.5 本地打包版，目前未发布。

铁锭故障截图已补入回归：检查两种配方的列表定位、真实铁锭详情不误判为钢锭，以及原料缺失/相近名称时不加工。其余材料的列表使用原始截图验证，详情名称另有合成测试；合成测试不代表已拿到每种材料的实机详情截图。全部 10 种材料检查单格、多格、跨轮次数、材料不足和领取流程；输入测试拦截所有 Win32 消息，不消耗真实游戏材料。
